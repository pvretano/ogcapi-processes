[%metadata]

[.component,class=part]
--
If the server does not support the media type of the request body of the replace operation, asserted using the HTTP header `Content-Type`, the server SHALL response with an HTTP status code `415`.
--

[.component,class=part]
--
The content of that response SHALL validate against the following OpenAPI schema fragment:

[source,yaml]
----
include::../../../../../../openapi/schemas/common-core/exception.yaml[]
----
--

[.component,class=part]
--
The `type` of the exception SHALL be `pass:["https://www.opengis.net/def/exceptions/ogcapi-processes-2/1.0/unsupported-media-type"]`.
--
