+
--

2. Execute test `/conf/create-replace-delete/create` of <<OAComm-5>>.

3. Fetch the description of the process according to test `/conf/core/process-description-op` of <<OAProc-1>>.

4. Inspect the process description and verify that the value of property that indicates whether the process is mutable or not is set to `true`.
