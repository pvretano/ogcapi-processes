====
[%metadata]
identifier:: /conf/dru/response-immutable
target:: <<req_deploy-replace-undeploy_response-immutable,/req/deploy-replace-undeploy/response-immutable>>
test-purpose:: Validate that the server generates an exception when an attempt is made to mutate and immutable process.
test-method::
+
--
1. Execute test `/conf/create-replace-delete/replace` or `/conf/create-replace-delete/delete` of <<OAComm-5>> to deploy the process.

2. Verify that the server responds with an HTTP status code of `403`.

3. Validate that the document in the response body is conform to the https://schemas.opengis.net/ogcapi/processes/part1/2.0/openapi/schemas/exception.yaml[exception.yaml] schema.

4. Verify that the exception type (member: `type`) is `https://www.opengis.net/def/exceptions/ogcapi-processes-2/1.0/immutable-process`.
--
====

NOTE: For a replace operation, first create a process description using some vocabulary supported by the server (e.g. <<clause_ogcapppkg,OGC Application Package>>).
