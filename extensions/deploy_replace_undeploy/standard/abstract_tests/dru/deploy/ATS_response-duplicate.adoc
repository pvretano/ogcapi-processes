[abstract_test]
====
[%metadata]
identifier:: /conf/dru/deploy-response-duplicate
target:: <<req_deploy-replace-undeploy_deploy-response-duplicate,/req/deploy-replace-undeploy/deploy-response-duplicate>>
test-purpose:: Validate that the server generates an exception when a process with a duplicate identifier is deployed.
test-method::
+
--
1. Create a process description using some vocabulary supported by the server (e.g. <<clause_ogcapppkg,OGC Application Package>>).

2. Execute test `/conf/create-replace-delete/create` of <<OAComm-5>> to deploy the process.

3. Verify that the server responds with an HTTP status code of `409`.

4. Validate that the document in the response body is conform to the https://schemas.opengis.net/ogcapi/processes/part1/2.0/openapi/schemas/exception.yaml[exception.yaml] schema.

5. Verify that the exception type (member: `type`) is `https://www.opengis.net/def/exceptions/ogcapi-processes-2/1.0/duplicated-process`.
--
