[%metadata]
identifier:: /conf/dru/deploy-unsupported-media-type
target:: <<req_deploy-replace-undeploy_deploy-unsupported-media-typ,/req/deploy-replace-undeploy/deploy-unsupported-media-type>>
test-purpose:: Verify that a HTTP status code `415` is generated when a request body is encoded using an unsupported media type.
test-method::
+
--
1. Execute test `/conf/create-replace-delete/create` of <<OAComm-5>> to deploy the process using a media type not supported by the server.

2. Verify that the server responds with an HTTP status code of `415`.

3. Validate that the document in the response body is conform to the https://schemas.opengis.net/ogcapi/processes/part1/2.0/openapi/schemas/exception.yaml[exception.yaml] schema.

4. Verify that the exception type (member: `type`) is `https://www.opengis.net/def/exceptions/ogcapi-processes-2/1.0/unsupported-media-type`.
