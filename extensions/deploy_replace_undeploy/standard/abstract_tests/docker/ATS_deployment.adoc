[[ats_docker_deployment]]

[abstract_test]
====
[%metadata]
identifier:: /conf/docker/deployment
target:: <<req_docker_deployment,/req/docker/deployment>>
test-purpose:: Verify that, if present, the value of the `deployment` member of the <<sc_ogcapppkg_execution-unit-property,`executionUnit`>> of an <<clause_ogcapppkg,OGC Application Package>> specifies a valid value.
test-method::
+
--
1. Obtain a process description for each process listed in the processes array (path: `/processes/{processID}`) by executing the `/conf/core/process-description-op` test from <<OAProc-1>>.

2. Inspect each process and verify that the `executionUnit` member is present.

3. If the `executionUnit` member is present, verify that the `deployment` member is present.

4. If the `deployment` member is present, verify that its value if one of: `local`, `remote`, `hpc` or `cloud`.
--
====
