[[ats_docker_image-ref]]

[abstract_test]
====
[%metadata]
identifier:: /conf/docker/image-ref
target:: <<req_docker_image-ref,/req/docker/image-ref>>
test-purpose:: Verify that the <<sc_ogcapppkg_execution-unit-property,`executionUnit`>> of an <<clause_ogcapppkg,OGC Application Package>> references a valid container image.
test-method::
+
--
1. Obtain a process description for each process listed in the processes array (path: `/processes/{processID}`) by executing the `/conf/core/process-description-op` test from <<OAProc-1>>.

2. Inspect each process and verify that the `executionUnit` member is present.

3. If the `executionUnit` member is present:
   . verify that the value of the `type` member is `docker` or `oci`,
   . verify that the `value` member is present and that it contains a child member named `image`

4. Take the value of the `image` member and using an appropriate tool (e.g. docker or podman) to inspect the image (e.g. `docker image inspect <image reference>`) in order to verify that it is a valid container image reference.
--
====
